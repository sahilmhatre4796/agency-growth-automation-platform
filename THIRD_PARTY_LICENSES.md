# Dependency and licensing policy

This package is custom original project documentation. The eventual application will contain third-party libraries and services subject to their own licenses and terms. Codex must inspect each library license and pin a maintainable version, generate an SBOM/package-lock, and document notices and attribution where applicable.

The project is currently intended for **internal ChainCraft Studio use**; no grant to resell n8n, managed AI models, contact data or provider APIs is implied. No open-source package can grant permission to scrape protected websites, auto-message LinkedIn members, or bypass provider messaging requirements.

The studio must choose an application source-code license and publish notices **before external distribution**; this planning package deliberately does not declare the future application to be open source.

## Optional voice dependency notice
Dograh, LiveKit Agents, Pipecat, telecom SDKs and individual STT/LLM/TTS services are *candidates*, not bundled code. Before installing any, record exact version/commit, SPDX licence, trademark constraints, runtime dependencies, SaaS hosting/redistribution permissions, commercial terms and third-party notices. Do not assume an open-source agent makes telephony or AI inference free.
