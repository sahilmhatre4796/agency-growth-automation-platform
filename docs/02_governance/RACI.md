# Governance / RACI

| Decision / Activity | Studio owner | AI coding agent | Legal adviser / provider |
|---|---|---|---|
| Approve product requirements | Accountable | Consulted | — |
| Implement and test code | Reviewer | Responsible | — |
| Approve real contact outreach | Accountable | Cannot authorize | Legal guidance |
| Accept Google OAuth scopes | Accountable | Suggest only | Google verification if required |
| WhatsApp onboarding | Accountable | Technical prep only | Meta/BSP approval |
| Comply with Indian privacy / direct marketing law | Accountable | Build controls | Qualified adviser consulted |
| Increase spend / upgrade plan | Accountable | Cannot purchase | Provider |
| Go-live | Accountable | Evidence and checklist | Providers / adviser where required |

All regulatory notes are design flags, not legal opinions.
